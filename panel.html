  • 1. Reach the upstream
  • 2. Map the model name your client sends

Request filters

    
A matching request is not sent upstream; the client receives a valid empty answer. Off by default. Do not filter requests with max_tokens 8192, because the client session may stop itself.

    

    
    

  






  

    
Style addon

    
Instructions appended to the system prompt of every request. Changing them rebuilds the prompt cache once. Empty by default.
